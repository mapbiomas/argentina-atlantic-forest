# Argentina - Atlantic Forest

Developed by the team of **MapBiomas Argentina**.

## About

This repository contains scripts for classifying and filtering the **Atlantic Forest** region in Argentina.

We highly recommend reading the [Atlantic Forest Algorithm Theoretical Basis Document (ATBD)](https://drive.google.com/file/d/1cDHBEH2nQLKdq2aKc2DF0juL2lOATks_/view?usp=drive_link/). This document provides fundamental information about the classification methodology and each processing step.
