# Argentina - Atlantic Forest

Developed by the team of **MapBiomas Argentina**.

## About

This repository contains scripts for classifying and filtering the **Atlantic Forest** region in Argentina.

We highly recommend reading the [Atlantic Forest Algorithm Theoretical Basis Document (ATBD)](https://bosqueatlantico.mapbiomas.org/atbd-entienda-cada-etapa/). This document provides fundamental information about the classification methodology and each processing step.
